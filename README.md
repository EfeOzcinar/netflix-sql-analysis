# 🎬 Netflix Data Analysis Project

This project explores Netflix's library using SQL to uncover insights about content types, genres, and country distributions.

## 📁 Dataset
- **Source**: [Netflix Titles on Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)
- **File**: `netflix_titles.csv`

## 📌 Questions Explored
- Which countries produce the most Netflix content?
- What are the most common genres?
- How has content type (Movie vs TV Show) changed over time?

## 🛠️ Tools Used
- MySQL
- VSCode / DBeaver / SQLite
- GitHub

## 📊 Key Insights
- USA and India are the top content producers.
- "Dramas" and "Documentaries" are the most frequent genres.
- TV shows are becoming more common since 2015.
